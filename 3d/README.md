# 圣光渣骑：我在异界当海王 · 3D 垂直切片

作者：Jack  
© Jack 版权所有 · 禁止任何形式转载

浏览器里可玩的第三人称 3D 奇幻 RPG 演示（约 10–15 分钟），世界观与 2D 版同一原创 IP。这不是成品 3A 商业游戏，而是一条能走完的演示环：标题 → 探索晨誓广场 → 与四位女主对话 → 接委托、打营地、击杀小首领 → 升级并接到后续剧情钩子。

## 如何运行

在本目录启动任意静态服务器：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173/`。线上路径为仓库 GitHub Pages 的 `/3d/`。

不要用 `file://` 直接打开（ES module / import map 需要 HTTP）。

## 操作

**电脑**
- WASD / 方向键：移动
- 鼠标：点击画面锁定指针后转动视角（按住右键也可）
- Shift：冲刺
- 空格：跳跃
- C：翻滚（短暂无敌）
- 左键 / J：十字圣击
- 1：圣光速疗　2：圣裁之锤　3：审判之光
- E：交谈 / 对话继续
- Tab：锁定敌人
- Esc / P：暂停

**手机**
- 左下虚拟摇杆移动，右侧拖动转向
- 攻 / 跳 / 滚 / 互动，以及底部技能栏

## 本切片内容

- 场景：白冠王国·晨誓圣堂广场（黄金时刻）→ 晨辉林小路 → 灰烬营地
- 可对话女主：奥罗拉·苍角、莉莉丝卡、艾莉安·月歌、薇欧拉·夜纱
- 技能：十字圣击、圣光速疗、圣裁之锤、审判之光（名称均为原创）
- 委托：驱散林间灰烬（灰烬狂徒 ×4 + 执事·焦喉）
- 钩子：第 37 页残页与天上的水晶方舟

## 画质

标题页和暂停菜单可切换 高 / 中 / 低。低画质会关闭泛光与阴影，方便手机游玩。
